## Before You Start (Beginner-Friendly Setup Guide)

Before running **v1.0** or **v1.1**, make sure your server and local machine are ready.

This section covers:

* Choosing a correct server
* SSH access
* Required OS
* Tools you need locally
* Basic commands you should know

Perfect for beginners or anyone touching a Linux VM for the first time.

---

### ✅ 1. Use the Right VM (Server)

Any Linux VM works, but the recommended:

* **Ubuntu 20.04** or **Ubuntu 22.04**
* 1 vCPU, 1–2GB RAM is enough
* Cloud providers you can use:

  * AWS EC2
  * DigitalOcean Droplet
  * Linode
  * Lightsail
  * Local VirtualBox VM

> Your deployment engine is designed for **Ubuntu**.
> (CentOS / RHEL will need different package install commands.)

---

### ✅ 2. Make Sure You Have the Server’s IP Address

You’ll need the **public IP** of your VM.

Example:

```
54.201.111.23
```

This is used when running:

```bash
scp ... ubuntu@<server-ip>:/tmp/
ssh ubuntu@<server-ip>
```

Replace `<server-ip>` with your real one.

---

### ✅ 3. Make Sure You Can SSH Into the Server

### If you're using AWS EC2:

* Download your `.pem` file
* Permissions:

```bash
chmod 400 mykey.pem
```

* SSH:

```bash
ssh -i mykey.pem ubuntu@<server-ip>
```

### If you're using any other VPS:

You normally SSH like this:

```bash
ssh ubuntu@<server-ip>
```

If you see:

> "Permission denied (publickey)"

Then your SSH key is not configured.

---

### ✅ 4. Install `git` and `scp` on Your Local Machine

You need these two tools to clone the repo and upload scripts:

```bash
sudo apt install git -y        # Linux
brew install git               # macOS
```

`scp` comes pre-installed on macOS and Linux.

For Windows users:
Use **Git Bash**, it already includes:

* ssh
* scp
* git

---

### ✅ 5. Make Sure You Have a GitHub Personal Access Token (PAT)

Your deploy script needs it to clone private repos.

PAT should have:

* `repo` scope
* (optional) `read:packages`

Create one here:
[https://github.com/settings/tokens](https://github.com/settings/tokens)

Store it safely.
The script will ask for it securely — it won’t be saved anywhere.

---

### ✅ 6. Know Where /tmp Is

When you upload scripts, they go to:

```
/tmp
```

This is a temporary folder.

After SSH-ing into server:

```bash
cd /tmp
```

From there you can run:

```bash
chmod +x deploy.sh
sudo ./deploy.sh
```

---

### ✅ 7. Know Your App Requirements

Your app should be:

* A Spring Boot app
* Built with Maven Wrapper (`mvnw`)
* Output a `.jar` file

The script assumes a Maven-based Java project.

---

### 🧩 That’s It

If you’re comfortable with:

* SSH
* uploading files
* running simple commands

…you are fully ready to go!
