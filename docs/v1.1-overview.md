# v1.1 Overview — Config-Driven Multi-DB Deployment

## Objective
Improve the v1.0 deployment script by adding configuration flexibility, security, and multi-database support.

---

## Enhancements
- Config file: `/etc/app-deploy.conf`
- Secure prompts for:
  - GitHub PAT
  - DB password
- Multi-DB support:
  - MySQL
  - PostgreSQL
  - MongoDB
- Cleaner directory structure
- Better readiness checks
- Stronger environment file permissions

---

## Why v1.1 Matters
This version introduces:
- declarative config
- DB-agnostic provisioning
- better security practices
- early infra-tool structures
- foundation for modular Go CLI in v2.0
