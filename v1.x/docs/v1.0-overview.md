# v1.0 Overview — Baseline Deployment Script

## Objective
Build a fully automated deployment script that takes a Spring Boot app, prepares the VM, configures the database, and runs the app as a systemd service.

---

## Features
- Install Java 17, MySQL, Git
- Start MySQL service
- Create database + user
- DB readiness check (retry loop)
- Clone GitHub repository
- Build with Maven Wrapper
- Normalize JAR artifact
- Generate environment file
- Create systemd service
- Start the service reliably

---

## Why v1.0 Matters
This version teaches:
- Linux services
- DB provisioning
- deployment flow
- repeatability
- environment management
- systemd lifecycle

It forms the foundation for all future versions.

---

## 🟩 Run v1.0

```bash
# 1. Clone the project
git clone https://github.com/manasa-bhagwat/vm-deploy-engine.git
cd vm-deploy-engine
```

```bash
# 2. Switch to version 1.0
git checkout version/1.0
```

✔ You are now using the basic version of the script.

```bash
# 3. Upload the script to your server
scp scripts/v1.0/deploy.sh ubuntu@<server-ip>:/tmp/
```

✔ Sends only the script (v1.0 has no config file yet).

```bash
# 4. SSH into your server
ssh ubuntu@<server-ip>
cd /tmp
```

```bash
# 5. Make the script executable
chmod +x deploy.sh
```

```bash
# 6. Run the script
sudo ./deploy.sh
```

✔ This version installs Java, Git, MySQL, clones your app, builds it, creates a systemd service, and starts it.
