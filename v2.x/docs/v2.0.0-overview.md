# v2.0.0 — Go CLI Bootstrap

## 🎯 Version Summary
v2.0.0 marks the beginning of the **Go rewrite** of vmdeploy.

This version introduces:
- A brand-new Go module (`go.mod`)
- A new `v2.x/` folder that becomes the home of all Go code
- The initial CLI entrypoint (`cmd/vmdeploy/main.go`)
- A clean foundation for future SSH, GitOps, Maven, Systemd, and deployment orchestration

This is where vmdeploy stops being a **Bash script**  
and starts becoming a **real cloud-native tool**.
